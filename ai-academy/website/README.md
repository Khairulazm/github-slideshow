# Website

A simple static site for the AI Academy. No build tools required.

## Local preview
- Open `index.html` directly in a browser, or
- Serve locally: `python3 -m http.server` and visit `http://localhost:8000/ai-academy/website/`

## Deploy options
- GitHub Pages: Serve the `website/` directory
- Netlify/Vercel: Drag‑and‑drop or set `website/` as the publish directory
- Any static host: Upload files in `website/`
