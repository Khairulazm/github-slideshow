# Quiz: Foundations

Select one answer per question.

1) Which is a limitation of generative AI?
A) It cannot summarize text
B) It may generate plausible but incorrect answers
C) It cannot change tone
D) It cannot follow structure
Answer: B

2) What is a prompt?
A) A dataset
B) A model weight
C) An instruction or input given to the model
D) A programming language
Answer: C

3) What reduces hallucinations?
A) Longer outputs
B) Adding unrelated examples
C) Verifying against source documents
D) Using more emojis
Answer: C

4) What is a context window?
A) A web browser feature
B) The amount of text the model can consider at once
C) A security setting
D) A type of dataset
Answer: B

5) Which should you avoid with sensitive data?
A) Redacting and anonymizing
B) Using approved tools with data controls
C) Pasting confidential data into unapproved tools
D) Breaking tasks into smaller prompts
Answer: C

6) A good prompt often includes:
A) Role, task, constraints, and output format
B) Only a single vague sentence
C) Hidden requirements
D) Jargon only experts know
Answer: A

7) Few‑shot learning in prompting means:
A) Training the model from scratch
B) Providing a few examples to guide behavior
C) Limiting output to a few sentences
D) Reducing compute costs
Answer: B

8) Chain‑of‑thought prompting is used to:
A) Prevent any mistakes
B) Encourage reasoning steps
C) Copy others' answers
D) Hide logic from users
Answer: B

9) Human‑in‑the‑loop means:
A) No humans involved
B) Humans approve or correct key steps
C) Full automation only
D) More servers
Answer: B

10) Best practice for evaluating AI output:
A) Assume it's correct
B) Use a single test case
C) Compare against trusted sources and test multiple cases
D) Avoid feedback loops
Answer: C
