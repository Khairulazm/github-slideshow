# No‑Code AI Automation

Duration: 8–12 hours
Prerequisites: Foundations, Prompting

## Outcomes
- Build simple automations using Zapier/Make and AI steps
- Create chatbots and forms that triage or draft content
- Log and monitor automations for reliability

## Modules
- Connectors: triggers, actions, webhooks
- Prompted transforms and validation
- Human‑in‑the‑loop approvals
- Logging, retries, alerts

## Project
- Automate one repetitive workflow from your role (e.g., intake → triage → draft → review)
