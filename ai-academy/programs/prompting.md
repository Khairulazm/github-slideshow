# Practical Prompting

Duration: 6 hours (workshop) or 1 week (self‑paced)
Prerequisites: Foundations

## Outcomes
- Write clear, structured prompts
- Use system/role, constraints, examples, and evaluation
- Create reusable prompt templates

## Core patterns
- Role + Task + Constraints + Output schema
- Few‑shot examples and counter‑examples
- Chain‑of‑thought and critique‑then‑revise
- Tool‑usage hints and data guards

## Exercises
- Rewrite ambiguous prompts into structured prompts
- Design a prompt for a repeatable report with an output JSON schema
- Build a mini prompt‑library for your job tasks

## Assessment
- Practical prompt portfolio (3–5 templates)
