# Capstone Project

Duration: 2–4 weeks alongside work
Prerequisites: All core modules

## Goal
Deliver a documented AI‑enabled workflow or asset that saves time or improves quality for a real stakeholder.

## Milestones
- Proposal (problem, users, risks, success metric)
- Prototype with test data
- Pilot with 3–5 real cases
- Final report with impact and next steps

See `../capstones/capstone-briefs.md` and `../assessments/rubric-capstone.md`.
