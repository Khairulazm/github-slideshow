# AI Academy (Non-Technical)

A complete, ready-to-run blueprint for launching an AI Academy for non‑technical learners. Includes programs, lesson templates, assessments, marketing assets, operations playbooks, policies, resources, capstones, B2B materials, schedules, and a simple static website.

## Who it is for
- Professionals in business, operations, HR, finance, sales, marketing, support
- Educators and administrators
- Entrepreneurs and freelancers
- Students and career switchers

## Outcomes
- Confidently use AI tools for everyday work
- Design effective prompts and workflows
- Evaluate risks, safety, and ethics
- Build lightweight no‑code AI automations
- Ship an AI-enabled capstone for a real use case

## Repository structure
```
ai-academy/
  programs/               # Detailed program tracks
  lesson-templates/       # Reusable lesson/session templates
  assessments/            # Diagnostics, quizzes, rubrics
  marketing/              # Landing copy, emails, social
  ops/                    # SOPs, facilitator guides, LMS mapping
  policies/               # AI usage, integrity, privacy, accessibility
  resources/              # Glossary, prompt library, cheat sheets
  capstones/              # Project briefs and grading rubrics
  b2b/                    # Enterprise proposal, pricing, ROI tools
  schedules/              # Sample schedules and calendars
  website/                # Static site for quick launch
```

## Quick start
- Customize `programs/*` to your audience and industry
- Duplicate a template from `lesson-templates/*` for each session
- Pull assessments from `assessments/*` and link in your LMS
- Publish the static site in `website/` using GitHub Pages or any static host

## Customization guide
- Start with `programs/foundations.md` for onboarding cohorts
- Layer `programs/productivity.md` and `programs/prompting.md` for skills
- Choose one functional track from `programs/ai-in-business.md`
- Add `programs/no-code-ai.md` for automation; close with `capstones/*`
